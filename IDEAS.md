# Ideas, not built

Things the owner mentioned that were deliberately left out of the first night. One line each.

- **CRT monitor wall:** the screen rendered as a wall of old CRT monitors, one agent per monitor.
- **Moving keyboard keys:** an on-screen keyboard whose keys press as the agent types commands.
- **Decompiler lab:** fast agents driving the reverse-engineering tools as another task family.
- **3D page thumbnails:** fetched web pages shown as floating 3D thumbnails in the graph.
- **Laser paths for decision calls:** a beam drawn from the extracting model to the decision model on every Jev call.
- **Voice-driven runs:** say a task to Vox and have it launch the agent (needs a Deepgram key; the panel has a typed fallback).
- **A real embedded terminal** in the bottom-left pane instead of the streaming log.
- **promptfoo** as the benchmark front end, reading `07-bench/results.jsonl`.
- **A teacher agent in the loop:** a larger model that watches failed traces and rewrites the cards on its own (tonight the card fixes were made by hand from failed traces).
- **Semantic file lookup card:** a local embedding search CLI next to `fd` / `rg` / `plocate` (candidates in `docs/research/file-finding-tools.md`).
