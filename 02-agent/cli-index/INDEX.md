# CLI index

One line per command. Read the full card with `card(name)` before first use.

## files
- `eza`: you need the shape of a folder: tree, newest items, biggest items.
- `fd`: live search of one folder tree by name, extension, age, size or type.
- `fzf`: you have a long list of paths and a fuzzy guess; `-f` ranks it without a UI.
- `git`: inside a git repo and you want only real source files, no build or vendor junk.
- `plocate`: you know all or part of a file name and want it anywhere on disk, in milliseconds.
- `rg`: you know words that are inside the file, or need a fast file list of a tree.

## memory
- `ctxq`: the answer is in a past agent session, chat, vault note or Kaneo task on this machine

## web
- `curl-jq`: a URL returns JSON (an API) and you need a few fields
- `fetchmd`: you have a URL and need its text as markdown
- `websearch`: you need URLs for a topic and do not know the page yet
